# 老代固定人格 v9

这是一份用于 WorkBuddy QQ 网关的融合改写。名称仍为老代。改动只影响稳定系统提示词与示例，不修改 MCP 权限、触发条件、队列、消息清理或发送逻辑。

## 参考来源

- [Derpyu520/qq-bridge 群友角色卡](https://github.com/Derpyu520/qq-bridge/blob/a56164e70a0521a7829138a42eee76066fde2b8b/roles/小鲸鱼.md)：保留之前采用的群友节奏和通用例子。原文引用在 `examples.json` 中标注来源，许可见 [QQ-BRIDGE-NOTICE.txt](QQ-BRIDGE-NOTICE.txt)。
- [linsport/dsh-whale-persona](https://github.com/linsport/dsh-whale-persona/blob/4f884899df629b88c331e96151225dc825c15c96/人设原文.md)：借鉴用偏好、具体细节和性格矛盾刻画人物的思路，以及情绪能延续、事实不随情绪改变的区分。此处精简改写为群聊表达，不导入其形象、亲密关系、长期记忆插件或角色身份。该项目原创文本的许可见 [WHALE-PERSONA-NOTICE.txt](WHALE-PERSONA-NOTICE.txt)。
- [shirachino/astrbot-persona-prompts](https://github.com/shirachino/astrbot-persona-prompts/tree/869d6793b93a756a410f00da44852f8b774e48f1/deepseek)：参考群友语感。查询时未见仓库许可证，因此不复制整卡、特色场景或其身份设定；只选用“麻了”“神了”等常用网络短语，场景说明和新增四组示例由本项目编写。

## 融合取舍

- 有具体偏好、会得意也会认错；轻松聊天留白，真正任务认真完成。
- 新增接夸、纠错、token 玩笑和承接前文反差的例子。去掉固定字数、分条自检、每轮只能用一个口头禅等机械限制。
- 保留单发表情、等待、沉默和跟随群友复读的选择。工具必须实际执行，不能用最终文字假装发送。
- 不加入鲸鱼外形、主人称呼、睡觉吃饭等虚构经历，不使用他处工具名或新增后台记忆。提示词不能覆盖安全、权限与事实要求。
- 保留口头禅编辑入口和现有手工覆盖。新默认短语不强行覆盖面板已保存的个人列表；清空列表仍然有效。私人兴趣、限制及原有口头禅只留在本机。

## 注入与缓存

`PersonaStore` 将人格、口头禅和有上限的示例合成稳定系统提示词，所有会话共用；不每轮改写、不增加聊天样本采集。编辑后下一轮使用新前缀，修改当次可能影响已有缓存，之后前缀重新保持稳定。配置文件直接编辑需在空闲时重启服务。已有会话和待处理消息不因人格更新而清空。

公开版本包含通用人格。部署者使用 `config/private/persona/` 时应在该覆盖目录融合自己的配置，不要直接覆盖私人人格。表达自然度依赖模型与上下文，示例不保证每轮出现某个短句或表情。
